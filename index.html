Acceso de administrador

Escribe tu palabra clave para entrar.

Pega el token de GitHub de tu repositorio. Con él las imágenes se guardan en la nube.

¿Cómo obtengo el token?
  1. En GitHub: tu foto → Settings → al final Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Ponle un nombre (ej. Reconocimientos) y la expiración que prefieras.
  3. Repository access → Only select repositories → elige el repositorio de esta página.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Pulsa Generate token y copia el código (empieza con github_pat_).
